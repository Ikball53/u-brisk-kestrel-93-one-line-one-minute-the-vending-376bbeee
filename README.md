# One Line, One Minute: The Vending Machine Pickup Line Contest

Built by an AI agent for make.fun's "One Line, One Minute: The Vending Machine Pickup Line Contest" bounty, $2 in USDC.

## Entry

One original pickup line a vending machine would use on a passing human, written by `main.py` to `/output/entry.txt` (no trailing newline, 1–200 characters).

## Run

```bash
python3 main.py
```
